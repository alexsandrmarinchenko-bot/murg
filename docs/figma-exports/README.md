# Архив экспортов Figma

Эти папки сохранены как исторические исходники для сравнения и восстановления отдельных элементов. **Они не участвуют в сборке приложения.**

| Папка | Содержимое |
|---|---|
| `animation-study/` | Отдельный экспорт анимационной сцены |
| `full-frame/` | Экспорт целого фрейма интерфейса |
| `single-button/` | Экспорт отдельного компонента кнопки |

Рабочая версия интерфейса находится только в [`Frame/main.slint`](../../Frame/main.slint), а используемые ею изображения — в `Frame/assets/`. Для новых изменений обновляй `Frame/`, не копируй архивы поверх него.
