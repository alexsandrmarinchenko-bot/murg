# Обновление интерфейса из Figma

Рабочий интерфейс приложения собирается из `Frame/main.slint`. Его компилирует `build.rs`. Папка `Frame/assets/` содержит только ресурсы, которые использует текущий интерфейс.

## Перед экспортом

1. Экспортируй только основной Frame интерфейса, не всю страницу с тестовыми вариантами компонентов.
2. Сохрани `main.slint` и соответствующие ресурсы в `Frame/assets/`; не создавай вложенность `Frame/Frame/`.
3. Сохрани интерактивные варианты `Default`, `Hover` и `Pressed` в Figma — они служат спецификацией визуального поведения.

## Важное про Prototype

Связи Figma Prototype (`While hovering → Change to → Smart animate`) сами по себе не становятся исполняемыми обработчиками Slint. Наведение, нажатие и анимации выполняются в `Frame/main.slint` через `TouchArea` и `animate`. После нового экспорта нужно сохранить эту логику и проверить сборку через `cargo check --locked`.

## Проверка ресурсов

Не удаляй файлы из `Frame/assets/` только потому, что они выглядят похожими: сначала проверь ссылки `@image-url(...)` и `Assets.*` в `Frame/main.slint`. Неиспользуемые ресурсы можно удалять отдельно после проверки ссылок.
