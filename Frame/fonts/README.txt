Font imports at the top of main.slint are commented out so the export can run in Slint development tools without the font files. Font binaries are not included; fallback fonts may change the text appearance and layout.
Add the following real font files, then uncomment their import lines in main.slint by removing the leading // to enable them.
Names below are expected filenames, not original Figma file paths. For OTF/TTC fonts, change the import extension to match.

fonts/inter-regular.ttf: Inter / Regular
