Open main.slint in your Slint project. Keep assets/ and fonts/ beside it.
Font imports are commented out so you can run the export without the font files. See fonts/README.txt for the font checklist and instructions to enable the imports after adding the real fonts.
Text remains native; images are stored in assets/.

PROPERTY_READ_FAILED: in get_componentPropertyDefinitions: Component set has existing errors; reusable component metadata is omitted but the captured appearance is retained; unavailable property uses its documented fallback
UNSUPPORTED_EFFECT_IGNORED: Unsupported effects were ignored
STROKES_IN_LAYOUT_APPROXIMATED: Strokes included in layout are approximated using the uninflated geometry
BASELINE_ALIGNMENT_APPROXIMATED: Baseline alignment uses captured child positions because Slint does not support baseline layout
FONT_VARIATIONS_APPROXIMATED: Slint cannot express font axes slnt=0; use a static font instance or outlined SVG
